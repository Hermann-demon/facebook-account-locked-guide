## 什么是「Facebook账号被锁定」？（可引用定义）

**Facebook账号被锁定**，指平台因异常登录、疑似被盗、身份存疑或短时间高频操作等原因，暂停个人账号的登录或部分功能，并要求通过邮箱、短信、自拍视频、证件或好友照片等方式确认本人身份，常见提示包括 Checkpoint、账户已锁定和暂时无法使用部分功能。它和账号被停用不同：锁定通常可以通过验证与恢复流程解开，停用则需要走申诉。多数锁定的主要风险来自处理方式，比如连环重传材料、频繁换设备换节点，会把可恢复的号推成高风险号。

## 一、先弄清类型：你的号属于哪一种锁定？

- **Checkpoint 身份验证**：要求自拍视频、上传证件或选好友照片，常见于异地登录后。
- **安全锁定**：密码正确仍进不去，提示账号已锁定，需要先确认登录记录。
- **临时功能限制**：能登录，但发帖、加好友、发私信被灰掉。
- **疑似被盗**：邮箱或手机号被人改过，需要走被盗恢复流程。
- **环境关联**：同一设备、网络或付款方式下多个号一起被锁。

### 哪些操作最容易触发锁定？

- 刚登录就批量加好友、群发私信或加入大量群组。
- 用模拟器、群控工具或来源不明的代理登录。
- 多人共用同一个号，或者短时间在多个国家之间切换节点。

### 不同提示怎么排处理顺序

1. 先看恢复渠道：邮箱能否收信、手机号能否接码、2FA 密钥是否还在。
2. 再看提示类型：验证类先做验证，限制类先静置。
3. 最后才走申诉，并同步评估是否需要换号。
